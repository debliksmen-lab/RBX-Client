# RBX Client (Roblox Launcher)

Лаунчер для быстрого запуска Roblox и режимов по Place ID с сезонными темами, экраном загрузки, звуками, режимом слабого ПК и просмотром профиля/друзей.

## Как скачать и запустить (для пользователей)
1. Перейди во вкладку **Releases** справа на странице репозитория.
2. Скачай свежий архив **`RobloxLauncher.zip`**.
3. Распакуй архив в отдельную папку (не запускай `.exe` прямо внутри архива).
4. Запусти `RobloxLauncher.exe` (при первом запуске Windows SmartScreen может показать предупреждение — нажми **«Подробнее» → «Всё равно выполнить»**).

## Запуск из исходников (Python)
```bash
pip install customtkinter pillow
python main.py
