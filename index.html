Возможности

О лаунчере RBX Client v1.4.1

Набор практичных инструментов для комфортной игры в Roblox без тяжёлых надстроек и лишних фоновых служб.

FPS

FastFlags & FPS Boost

Гибкая настройка лимита кадров, выбор движка рендера (DirectX 11, DirectX 10, Vulkan, OpenGL), отключение теней, травы и размытия через ClientAppSettings.json с готовыми пресетами под ваш ПК.

SRV

Server Hopper

Быстрый поиск публичных серверов по Place ID с сортировкой по числу игроков и пингу, а также мгновенный вход на самый пустой сервер или автоматический полноэкранный режим F11.

ID

Профиль и возраст аккаунта

Автоматическое определение локального аккаунта Roblox по открытым данным и логам, расчёт точного возраста аккаунта, просмотр друзей, описания и режим скрытия личных данных на экране.

AI

ИИ-помощник (400 сообщ./день)

Встроенный текстовый ассистент RBX AI с суточным лимитом до 400 сообщений в день поможет с настройками графики, ошибками подключения, кодом и любыми вопросами в рамках правил безопасности.

FIX

Авто-лечение багов (Self-Heal)

Система самодиагностики проверяет целостность JSON-конфигов, создаёт резервные копии .bak при сбоях, удаляет битые файлы кэша изображений и применяет тихие хотфиксы.

RUN

Авто-закрытие / сворачивание после старта игры

Настраивайте поведение окна лаунчера после запуска плейса: автоматическое сворачивание в панель задач Windows, привязку протокола rbxclient:// и быстрый возврат к игре.
